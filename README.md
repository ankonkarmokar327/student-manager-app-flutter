🎓 Student Manager App
A Flutter-based Student Management Application that uses SharedPreferences for local data storage.

This application allows users to log in, manage student information, save data locally, and perform student management operations through a clean and user-friendly interface.

🚀 Features
✅ Login Screen

✅ Remember Me Functionality

✅ Logout System

✅ Add Student

✅ View Student List

✅ Delete Student

✅ Form Validation

✅ Floating Action Button (FAB)

✅ Local Data Storage using SharedPreferences

✅ Clean UI Design

✅ Multi-Screen Navigation
